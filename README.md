# iptv_player

Player IPTV: link M3U o codice Xtream, TV diretta, film, serie, preferiti, ricerca.
Interfaccia scura con accento rosso. Nessun contenuto incluso.

## Compilare senza installare nulla (GitHub)
1. Crea un repository su github.com e carica questa cartella.
2. Scheda "Actions" > "Build app" > "Run workflow".
3. A fine lavoro, in fondo alla pagina scarica:
   - android-apk: file .apk per Android e Firestick
   - windows-app: cartella con l'app per Windows (avvia iptv_player.exe)

## Uso
- Tocco/clic: apre il contenuto. Pressione prolungata su un canale: preferiti.
- Impostazioni (icona in alto a destra): aggiorna playlist, esci.

## Da fare
VPN, EPG (guida programmi), riprendi da dove eri, controlli TV su Firestick, iOS.
